# Закреплённый корневой сертификат Supabase

Соединение с пулером (`*.pooler.supabase.com`) идёт по TLS, но цепочка обрывается на
собственном корне Supabase — в системном хранилище CA его нет. Чтобы не отключать проверку
сертификата (иначе пароль базы шёл бы по неподтверждённому каналу), корень лежит здесь и
подставляется в `ca` при подключении: `scripts/migrate.mjs`.

- Файл: `supabase-root-2021-ca.pem`
- Subject / Issuer: `CN=Supabase Root 2021 CA` (самоподписанный)
- Действует до: `2031-04-26`
- SHA-256 отпечаток:
  `80:70:25:AD:50:D4:ED:21:9D:2C:9C:7D:29:9C:00:4F:82:4E:B0:0C:F7:F6:5A:FE:F6:07:D0:7B:72:E6:CA:FA`

Смысл закрепления: первый вывод получен от сервера Supabase, дальше любое соединение с другим
сертификатом на том же имени будет отклонено, а не принято молча. Если Supabase сменит корень,
нужно сверить новый отпечаток с их документацией и обновить файл — это осознанный шаг, а не
автоматический.

`supabase-intermediate-2021-ca.pem` — промежуточный сертификат той же цепочки, хранится,
чтобы сборка проходила без сети.
